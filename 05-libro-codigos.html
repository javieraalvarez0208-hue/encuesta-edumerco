5  Libro de códigos

Para el uso adecuado de la base de datos EDUMERCO Adultos, se recomienda trabajar con el libro de códigos que se presenta a continuación. Esta sección busca facilitar el uso de la base de datos, entregando los nombres de las variables, sus etiquetas y las etiquetas de las categorías de respuesta.

Cada libro muestra el código de cada variable (name), la etiqueta asociada al ítem (label) y las categorías de respuesta con sus códigos (value_label).

Se puede usar el buscador del inicio de la tabla para filtrar por cualquier columna, o los buscadores individuales de cada columna para refinar la búsqueda.

5.1 Módulo A. Caracterización inicial

En el primer módulo, las preguntas buscan caracterizar a los participantes de la encuesta.

5.2 Módulo B. Meritocracia

En el módulo de meritocracia se realizan preguntas sobre la importancia del mérito en Chile y las oportunidades para acceder a mayores recompensas.

5.3 Módulo C. Actitudes hacia la desigualdad

En este módulo las preguntas están orientadas a las actitudes hacia la desigualdad.

5.4 Módulo E. Valores sociales

En este módulo se presentan tipos de personas y se pregunta el grado de similitud con el participante.

5.5 Módulo F. Cohesión social

En este módulo se realizan preguntas sobre convivencia con el resto de personas dentro de la sociedad.

5.6 Anexo. Módulo D. Experimento factorial de viñetas

El módulo D corresponde al experimento factorial de viñetas. Debido al elevado número de variables que lo componen, se presenta en un anexo separado.
